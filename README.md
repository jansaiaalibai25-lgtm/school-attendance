# school-attendance
# ШколоПосещаемость — веб-приложение для учёта посещаемости учеников школы

**Автор:**  Әлібай Ж, группа ВТиПо-2026
**Дисциплина:** [Системный анализ и дизайн]

## О проекте
Веб-приложение для учёта посещаемости учеников школы.
Роли: учитель, классный руководитель, родитель, завуч.

## Стек технологий
- Python 3 + Flask
- SQLite
- HTML/CSS + Bootstrap
- GitHub (для хранения кода)

## Документация
- Отчет по лабораторной работе: в папке `docs/` 
- UML-диаграммы: в папке `diagrams/`

## Как запустить (если есть код)
1. Установить зависимости: `pip install -r requirements.txt`
2. Запустить сервер: `python app.py`
3. Открыть в браузере: `http://localhost:5000`
